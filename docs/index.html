One AGENTS.md, every tool.

Sync your AI coding instructions across every tool on your machine — with zero magic, just symlinks.

By Sam Rogers, Snap Synapse · Published April 14, 2026 · Last updated September 5, 2026 · v0.6.0 · MIT

Different tools want different files at project root: AGENTS.md, CLAUDE.md, GEMINI.md, .cursorrules. There’s no standard, and waiting for one is expensive. Agentlink keeps them in sync through symlinks. Edit one, every tool sees the change.

AGENTS.md # real file you edit CLAUDE.md -> AGENTS.md GEMINI.md -> AGENTS.md .cursorrules -> AGENTS.md .github/copilot-instructions.md -> ../AGENTS.md

Why Agentlink?

Creating AI instruction files is cheap — keeping them in sync is the hard part. Good instruction files matter, and they’re often generated by expensive models. Agentlink fixes the sync problem the boring way: one real file, many aliases.

One real file, many aliases

Pick a source (AGENTS.md, CLAUDE.md, whatever). Every other tool file is a symlink to it. No duplicates, no drift.

Layer when needed

If one tool needs extra guidance, keep its wrapper real, import the shared source, and omit that wrapper from Agentlink. Identical aliases stay linked; tool-specific layers stay explicit.

Zero codegen

No templates, no transforms, no surprise diffs. Symlinks are a 50-year-old OS feature. Edit the source, every tool sees it instantly.

Future-proof

Tomorrow’s AI tool wants workspace/ai/newthing.md? Add it to the config. Agentlink creates the directories and wires the link.

Project and global

Works in repos and under ~/.config/. Each agentlink sync selects one scope: the current project config when present, otherwise the global config. Use sync --global to explicitly select global scope.

Idempotent

Re-run safely. Missing aliases are created; replacement of broken or misdirected links requires explicit --force. Real files are never silently overwritten; preview with dry-run, back up, or force only after inspection.

Automatic triggers

Built-in git hooks, shell hooks, and launchd integration keep things synced without you remembering to run it. Hook installs quote paths safely and refuse ambiguous relative Git hook paths.

Scope is deliberately narrow: instruction files only. No MCP config, no chain configs. Simple on purpose.

Supported platforms and AI tools

Release binaries support macOS and Linux, each on ARM64 and x86-64 (AMD64). Git and zsh hooks work on both systems; launchd is macOS-only. Native Windows is not a supported release target. WSL uses the Linux binary, but is not a separate tested platform.

Agentlink v0.6.0, September 5, 2026. This listing describes the released registry, including vendor references and client caveats.

Native means the client reads AGENTS.md at the stated scope. Configurable and import modes require setup in that tool. Symlink means Agentlink creates an alias at the listed project path. Global paths are separate instruction scopes, not settings files. Detection is a heuristic, not proof that a tool loaded the instructions.

Install

Pre-built binaries for macOS and Linux are on the v0.6.0 release page. Or install directly with Go 1.23+.

Homebrew (macOS and Linux)

brew install snapsynapse/tap/agentlink

# Verify
agentlink --version

Go install

go install github.com/snapsynapse/agentlink/cmd/agentlink@latest

# Verify
agentlink --help

Source builds require Go 1.23 or newer. CI verifies Go 1.23.12, 1.26.8, and 1.27.1, with Go 1.27.1 also covered on macOS.

Pre-built binary

# macOS (Apple Silicon)
curl -L -o agentlink https://github.com/snapsynapse/agentlink/releases/download/v0.6.0/agentlink-darwin-arm64
curl -L -o SHA256SUMS.txt https://github.com/snapsynapse/agentlink/releases/download/v0.6.0/SHA256SUMS.txt
grep ' agentlink-darwin-arm64$' SHA256SUMS.txt | sed 's/agentlink-darwin-arm64/agentlink/' | shasum -a 256 -c -
chmod +x agentlink && mv agentlink /usr/local/bin/

# macOS (Intel) / Linux
# Replace darwin-arm64 with darwin-amd64, linux-amd64, or linux-arm64

Checksums in SHA256SUMS.txt on the release page.

Usage

Declare your source file and the aliases you want. Agentlink creates and repairs the symlinks.

Project config

# .agentlink.yaml (in project root)
source: AGENTS.md
links:
  - CLAUDE.md
  - GEMINI.md
  - .cursorrules
  - .github/copilot-instructions.md

From the project directory:

agentlink sync --dry-run
agentlink sync

Global config

# ~/.config/agentlink/config.yaml
source: ~/AGENTS.md
links:
  - ~/.claude/CLAUDE.md
  - ~/.codex/AGENTS.md
  - ~/.gemini/GEMINI.md
  - ~/.config/opencode/AGENTS.md

From a directory without a project config, run agentlink sync. Use explicit global selection from any directory:

agentlink sync --global --dry-run
agentlink sync --global

Layered Claude wrapper

# Keep CLAUDE.md out of .agentlink.yaml.
# CLAUDE.md remains a real committed file.
@AGENTS.md

## Claude-specific guidance
Use plan mode under src/billing/.

Agentlink does not generate or rewrite wrappers. Import expansion and nested precedence remain the consuming tool’s responsibility. Limited Edition Jonathan’s AGENTS.md guide for the CEO of Shopify explains the nested symlink workaround behind the “symlink by default, real wrapper at exception points” recommendation.

Detect installed tools

# Scan the system for AI tool installs
# and report what's found.
agentlink detect

# Prefer native/config/import guidance.
agentlink detect --generate --prefer-native

# Walk a directory tree and wire up
# symlinks in every repo with AGENTS.md.
agentlink scan ~/Git

# Also link beside nested AGENTS.md files
# in repos without .agentlink.yaml.
agentlink scan ~/Git --nested

An explicit .agentlink.yaml is authoritative. Automatic scanning preserves existing real wrappers unless --force is supplied. Nested mode creates only aliases with documented nested discovery; unknown tools remain root-only. Deterministic integration tests verify exact topology, idempotence, and byte-preserving dry runs.

Automatic triggers

# Install git/zsh hooks (plus launchd on macOS) so
# sync runs without you thinking about it.
agentlink hooks install --all

# Relative global core.hooksPath values
# are refused; use an absolute path.

# Remove cleanly.
agentlink hooks remove --all

Safe replacement

# Preview without creating, removing,
# or backing up files.
agentlink sync --dry-run

# Back up regular files before replacing.
agentlink sync --backup

# Replace regular files or conflicting links.
agentlink sync --force

Directories and special files are never replaced recursively.
